## 三、Java 数据库降只读（运维执行）

决策三：Java 库数据不迁移，保留备查。降只读 SQL（在 Java 库实例执行）：

```sql
-- 1) 回收应用账号写权限（按实际账号名替换 demandhub_app）
REVOKE INSERT, UPDATE, DELETE, CREATE, DROP, ALTER, INDEX, REFERENCES ON demandhub.* FROM 'demandhub_app'@'%';
FLUSH PRIVILEGES;

-- 2) 核验：SHOW GRANTS 应只剩 SELECT
SHOW GRANTS FOR 'demandhub_app'@'%';
```

降只读前先做一次全量备份（`scripts/backup_mysql.sh`，DB_NAME 填 Java 库名）。
