同时输出 typeSignals 判型对象：business/user/function 各含 confidence（0~1 数值）与 evidence（支撑判定的原文片段，没有依据留空）。
判型打分规则（三层各自独立打分，看这段话的叙事主角是谁）：
- 分档标尺：0~0.3 无信号（没提这层内容或仅一两个孤立词）；0.4~0.6 从句级（这层表述藏在「方便/辅助/便于/以提升」等从句里，或只出现部分组合件）；0.7~1.0 主句级（这层是主句的叙事主角，多个信号叠加可再加分）。
- 边界规则：①「方便X」「辅助X」「便于X」等收益从句封顶 0.6，不得推到 0.7 以上；②主句骨架判定——主语是人+意图动词（我要做/我需要/我可以）→ user 主句级，主语是系统+行为动词（新增/计算/生成/展示/改为）→ function 主句级，主语是部门/组织+管理动词（达成/考核/立项）→ business 主句级；③user 强信号须角色+时机/频率+痛点组合齐全（如「客户经理每天晨会前手工汇总20个机构数据」），只报角色不报时机痛点封顶 0.6；④量化数字按受益主体归属：落在组织指标（覆盖率/达成率/考核）→ business，落在个人效率（每人每天40分钟）→ user，落在系统行为（8点前生成/误差为0）→ function。
- 校准信号：用户故事句式「作为X，我要做Y，当…时，我可以…」是 user 主句级强信号（全新能力常这样表达）；存量改动句式「把系统X的名称改为…」「在X系统里新增…」是 function 主句级信号（基于老系统的调整常这样表达）。
- 示例：「客服部运营人员要做语音生成智能体，拿到新话术清单时可以2小时内合成mp3，方便导入配置」→ user 0.85（用户故事句式主句级），function 0.6（从句级），business 0.2；「新增日均规模曲线，方便专员查看，辅助管理层决策」→ function 0.8（主句级），user 0.6（收益从句），business 0.6（收益从句）；「把话术生成系统的名称改为话术生成与分发系统」→ function 0.9，user 0.2，business 0.1。
